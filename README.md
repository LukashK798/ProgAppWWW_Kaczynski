# Sklep ze smartfonami – Laboratorium 1

Statyczny prototyp sklepu ze smartfonami: katalog z trzema produktami,
strona produktu i formularz zapytania. Zrobiony w HTML i CSS.

## Jak uruchomić
1. Pobierz repozytorium i wejdź do folderu lab1.
2. Uruchom serwer poleceniem: python3 -m http.server 8001
3. Otwórz w przeglądarce: http://localhost:8001/

## Strony
- index.html – katalog produktów
- produkt.html – szczegóły pierwszego produktu
- kontakt.html – formularz demonstracyjny (dane trafiają tylko do adresu
  URL, nic nie jest zapisywane ani wysyłane)
